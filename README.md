# Android Package Inspector

A **zero-dependency** Python tool that inspects the packages installed on an
ADB-connected Android device, scores each app for risk (adware / spyware /
bloatware traits), and serves a local web UI to view, group, and manage apps in
batch.

Everything runs on the Python standard library and the platform-tools `adb`
binary — no pip installs, no framework, no external services.

## Features

- **Risk scoring** per app: overlay, accessibility services, boot autostart,
  foreground services, internet access, unknown installer, exported services and
  an untrusted-signature heuristic.
- **Criticality detection**: curated list + keyword heuristics for banking,
  finance, social and messaging apps, which require explicit confirmation before
  any destructive action.
- **Bloatware tagging** from a curated `bloatware.json` list (optional).
- **Reversible management**: freeze (`pm disable-user`, reversible) is the
  default recommendation; per-user uninstall is only offered for user apps.
- **Wireless ADB**: connect by IP (`adb connect`), Android 11+ pairing
  (`adb pair`) and mDNS discovery — with a dialog that opens automatically when
  no USB device is found.
- **Local single-page UI** (dark/light), plus a headless **CLI report** and
  **JSON/TXT export**.
- **Offline mode**: load a previous `report.json` and browse it with no phone.

## Requirements

- Python **3.10+** (developed on 3.12).
- Android **platform-tools**: `adb` available in the project directory, on
  `PATH`, or passed via `--adb`.
  - Wireless **pairing** requires platform-tools 30+ (`adb 1.0.41+`).

## Quick start

```bash
# Scan user apps and open the web UI
python3 android_inspector.py

# Include system apps
python3 android_inspector.py --all

# Headless console report + report.json + recommendations.txt
python3 android_inspector.py --cli

# Or, equivalently
python -m apinspector
```

Point at a specific adb binary or device:

```bash
python3 android_inspector.py --adb /path/to/adb --serial 192.168.1.50:5555
```

Reopen a previous scan without a device:

```bash
python3 android_inspector.py --report report.json
```

### Common options

| Option | Description |
|---|---|
| `--all` | Include system apps (default: user apps only) |
| `--cli` | Headless report + JSON/TXT export |
| `--serial` | Target a specific device serial |
| `--adb` | Path to the `adb` binary |
| `--port` | Web UI port (default `8765`) |
| `--no-open` | Do not open the browser |
| `--dry-run` | Log actions but never touch the device |
| `--report` | Load an existing `report.json` (offline mode) |
| `--out-dir` | Output directory |
| `--no-color` | Disable colored CLI output |

## Wireless ADB

If no USB device is detected, the UI starts in *no-device* mode and opens a
WiFi dialog with three tabs:

1. **IP directa** — `adb connect host:port` (default port `5555`). The device
   must already be listening on TCP (one-time `adb tcpip 5555` over USB, or a
   device with TCP already enabled).
2. **Pairing Android 11+** — enter the phone's *Wireless debugging → Pair device
   with pairing code* values: IP, pairing port and 6-digit code. After a
   successful `adb pair`, the tool auto-connects (mDNS) or falls back to the
   discovered `_adb-tls-connect._tcp` service.
3. **Discover** — list mDNS services advertised by the phone and fill the form
   with one click.

> QR-code pairing is **not** supported: the QR is generated by Android Studio's
> ddmlib, not by the `adb` CLI. Use the pairing-code flow instead.

## Safety model

Enforced in the backend, not just the UI:

- System apps can only be **frozen**, never uninstalled.
- Critical apps (banks, social, messaging) require explicit confirmation.
- Freeze (`pm disable-user`) is reversible with unfreeze (`pm enable`) and is
  always the recommended option over uninstall.
- `pm uninstall --user 0` removes the app for the current user only; it does not
  delete a system APK from the partition.

## Project layout

```
android_inspector.py        Thin launcher (shim)
apinspector/
  paths.py                  Filesystem locations
  util.py                   Shared helpers
  config.py                 Permissions, critical packages, weights, templates
  adb.py                    ADB client + adb output parsing
  wifi.py                   Wireless ADB (connect / pairing / mDNS)
  collectors.py             One-shot global device collectors
  parsing.py                Per-package dumpsys parsing
  scoring.py                Criticality, risk scoring, bloatware, report packing
  scanning.py               Scan orchestration (batch + streaming)
  actions.py                Freeze / unfreeze / uninstall with safety gates
  exporters.py              report.json + recommendations.txt
  report.py                 Console report rendering
  icons.py                  App icon service (cache + Play CDN + SVG fallback)
  cli.py                    Arguments + entry-point orchestration
  web/
    server.py               Local HTTP API and static UI server
    static/                 index.html · app.css · app.js
tests/                      unittest suite
bloatware.json              Optional bloatware dataset (see License)
```
